# MeritDesk.AI MCP setup

The connector is a **remote Streamable HTTP** MCP server at:

```text
<CONNECTOR_PUBLIC_ORIGIN>/api/mcp
```

That origin is **only** `CONNECTOR_PUBLIC_ORIGIN`. It is never taken from `Host`, `X-Forwarded-Host`, or port 3000.

## 1. Set the public origin

Copy `.env.example` to `.env.local` if you do not already have one. Do not commit `.env.local`. Set **one** origin per environment:

| Environment | Example |
| --- | --- |
| Local webpack-dev (this repo often uses 3101) | `CONNECTOR_PUBLIC_ORIGIN="http://127.0.0.1:3101"` |
| Local `next start` (this repo often uses 3100) | `CONNECTOR_PUBLIC_ORIGIN="http://127.0.0.1:3100"` |
| Staging | `CONNECTOR_PUBLIC_ORIGIN="https://staging.example.com"` |
| Production | `CONNECTOR_PUBLIC_ORIGIN="https://app.example.com"` |

Rules:

- Origin only: no path, query, or fragment. Do not append `/api/mcp`.
- `http://` is allowed **only** for `localhost` / `127.0.0.1`.
- Claude Desktop, claude.ai, and ChatGPT need a **public HTTPS** origin. Loopback HTTP is for local protocol tests; hosted OAuth will not complete against it.
- Restart the web process after changing the variable.

Invalid or (in production) missing values fail at startup (`src/instrumentation.ts`) and the MCP endpoint answers 500 instead of inventing a URL.

The value in the **process environment** wins, including a leftover `http://127.0.0.1:3000` inherited from a parent shell. `PORT` and the request Host are not used to rewrite it. If `/setup` copies port 3000 while you are listening on 3100 or 3101, set `CONNECTOR_PUBLIC_ORIGIN` to the listen origin and restart.

## 2. MCP and OAuth URLs (same origin for the resource)

| Piece | Value |
| --- | --- |
| MCP endpoint | `{CONNECTOR_PUBLIC_ORIGIN}/api/mcp` |
| Protected resource metadata | `{CONNECTOR_PUBLIC_ORIGIN}/.well-known/oauth-protected-resource` |
| Billing links in connector refusals | `{CONNECTOR_PUBLIC_ORIGIN}/billing` |
| OAuth **issuer** | Clerk Frontend API (`CLERK_OAUTH_ISSUER` or decoded from `NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY`). This is **not** the MCP origin. |
| Authorization-server metadata | Proxied from Clerk at `{CONNECTOR_PUBLIC_ORIGIN}/.well-known/oauth-authorization-server` |
| OAuth callbacks | Claude/ChatGPT redirect URIs, configured in **Clerk**, not generated by this app |

The `/setup`, `/connect`, and Firm pages copy `{CONNECTOR_PUBLIC_ORIGIN}/api/mcp` exactly and state whether HTTPS is required. Loopback HTTP is labelled as local-only. Hosted Claude Desktop, claude.ai, and ChatGPT need a public HTTPS origin. If `PORT` disagrees with a loopback origin, those pages warn but still copy the configured URL.

## 3. Clerk (required for a live handshake)

Do not bypass or mock token checks.

- `NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY`, `CLERK_SECRET_KEY`, `CLERK_WEBHOOK_SECRET`
- Organizations on; custom scope `practice:connector`
- **Opaque** access tokens (`oat_…`)
- Default dynamic-client scopes: `openid profile email user:org:read practice:connector`
- CIMD published; PKCE on
- Optional `CLERK_OAUTH_ISSUER=https://<clerk-frontend-api-host>` if it differs from the publishable key

## 4. Claude Desktop / claude.ai

1. Public HTTPS MCP URL: `https://<host>/api/mcp`
2. Settings → Connectors → Add custom connector
3. Name `MeritDesk.AI`, paste the URL, leave client ID and secret empty
4. Connect → sign in to MeritDesk → choose the firm

```bash
claude mcp add --transport http meritdesk https://<host>/api/mcp
```

There is no stdio / `claude_desktop_config.json` command for this server.

## 5. ChatGPT

1. Public **HTTPS** URL only
2. Plugins → Add custom MCP server → OAuth
3. Business / Enterprise / Edu for write tools

## 6. After the first connection

Set `CONNECTOR_ALLOWED_CLIENT_IDS` from unrecognized client ids on the Firm page, or case-work tools stay hidden (library tools still work).

# Getting the expedite request in front of USCIS

Every value here is `[VERIFY]` until confirmed in session against uscis.gov. Last confirmed August 14, 2026.

**The point of this file:** the letter is the substance of the request, not the request itself. USCIS dockets expedite requests through specific channels. A letter mailed to a lockbox intake address is very often filed to the case and never read as an expedite request. Decide the channel before drafting and say so in the output.

---

## 1. Prerequisites USCIS states

- The case must be **receipted**. Generally no expedite request before a receipt notice exists.
- Check **posted processing time** first, and check case status.
- Complete any **pending action on the case** first: biometrics, an outstanding RFE, an unanswered notice. An expedite request on a case that is waiting on the client is a request that will be declined.
- Confirm **premium processing is not available**, which for the I-130 it is not.
- Have the **receipt number** ready.
- **Make only one request.** USCIS asks this directly to reduce duplicate work, and duplicate requests can slow the case.

---

## 2. Channels

Verify the current channel list before choosing. As last confirmed:

**USCIS online account, secure message.** The cleanest channel where it is available: the request is written to the case, evidence uploads attach to it, and the office keeps a timestamped record. Requires the case to be visible in an account and, for the office to use it, the representative linkage on the account. Confirm the client's account holds this receipt and that the office is linked before choosing this route.

**USCIS Contact Center.** Live assistance, and the Emma assistant, can take an expedite request. Where the request is made this way, USCIS provides instructions for submitting the supporting evidence. Expect the letter and exhibits to go up as an upload or to be mailed to a stated address afterward, not to be read over the phone. Capture the reference or service request number.

**Mail or delivery to the office holding the case.** The channel the firm's filed letters use. It works where the letter reaches an office that processes correspondence on a pending case, which is why the Attn line matters, `Attn: Expedite` at a field office being an example. It is the weakest channel for docketing, because lockbox intake addresses are built for new filings. Before choosing it, verify the correct **correspondence** address for the office holding this case, which is frequently not the intake address printed on the receipt notice, and note that the USPS address and the courier address differ.

**Best practice, ADDED.** Where the online account channel is available, submit there and keep the same letter and exhibit set as the upload. Where it is not, make the request through the Contact Center, then send the letter and exhibits by the method USCIS specifies in that interaction, and save the reference number. Either way the office ends the day with a record of the date the request was made.

---

## 3. What goes with the letter

- The **letter**, signed.
- The **exhibits**, lettered to match the letter, legible, correctly oriented, and each one actually referenced in the letter.
- The **G-28**, where the office is not already attorney of record on this receipt, or where an updated G-28 is part of the ask.
- A **certified English translation** with the translator certification for every foreign language document.

For an upload, confirm the current file format and size limits, convert to a clean scan, and check that a multi page exhibit is one file in the right order. A rotated or illegible medical letter is the same as no medical letter.

---

## 4. After it goes in

- Save proof of submission the same day: the secure message thread, the service request or reference number, or the delivery tracking.
- Calendar a **follow-up date**. USCIS is not required to respond to an expedite request at all, so the calendar entry is the only thing that surfaces silence.
- Calendar any date the request is racing: the hearing date, the age-out date, the treatment milestone.
- Do not file a second request. Where more is needed, escalate rather than repeat.

---

## 5. Escalation, for the attorney to consider, not for the letter

Named here so the output can point at the next step. None of these belongs in the letter to USCIS.

- **Congressional casework.** The petitioner's own senator or representative, through a privacy release. Frequently the most effective next step after a declined or ignored expedite request.
- **DHS CIS Ombudsman, Form DHS-7001.** Generally expects that USCIS was asked first, which is another reason to keep proof of the request.
- **Outside-normal-processing-time inquiry.** A different request from an expedite request, available where the case is past posted processing time. It can be made in addition, and the output should say which requests are being made.
- **Mandamus or APA litigation.** Attorney decision, entirely outside this skill.
